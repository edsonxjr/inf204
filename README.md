Funcionamento e Evolução das Práticas Laboratoriais

Prática 01: Estabelece o "Hello World" e introduz componentes essenciais, evoluindo para a criação de um contador numérico que manipula a interatividade básica através do hook useState.  

Prática 02: Foca na sintaxe do JavaScript moderno e nas propriedades do JSX. Os alunos constroem listas dinâmicas de tarefas aplicando métodos de array, como o map, e técnicas de renderização condicional.   

Prática 03: Explora a organização espacial e visual através do Flexbox e do StyleSheet. O funcionamento da interface nativa é demonstrado utilizando componentes centrais como View, Text, Image e campos interativos na construção de um cartão de perfil.   

Prática 04: Aprofunda a lógica de controle e fluxo de estado criando um simulador de urna eletrônica. O foco é a mutação segura dos dados com base em seus estados anteriores e o cálculo de dados derivados matematicamente no corpo do componente.   

Prática 05: Resolve problemas nativos de performance na rolagem de tela implementando o conceito de virtualização. Os alunos aprendem a dominar a API FlatList, suas propriedades de renderização e tratamentos de estado vazio enquanto desenvolvem uma agenda telefônica contendo separadores.   

Prática 06: O roteiro final ensina o roteamento do aplicativo integrando e configurando a biblioteca React Navigation. O processo envolve organizar o código em pastas específicas de telas e rotas para aplicar paradigmas de navegação em pilha (Stack) e em abas (Bottom Tabs), permitindo a passagem estruturada de parâmetros.
